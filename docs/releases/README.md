1. 发版或合并一版可对外说明的能力时，新增 `docs/releases/X.Y.Z.md`，并更新上表。

3. 本机过程材料如需留档，仅放 `docs/reports/`（见该目录 README）；不得写入真实姓名、业务项目名或其它测试隐私数据，且默认不进入发行包。
